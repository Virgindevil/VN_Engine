VNKit — лёгкий движок визуальных новелл для Unity 2022.3+
=========================================================

Пользовательский интерфейс полностью создаётся программно (без префабов).
Сценарии представляют собой обычные текстовые файлы `.vns`.
Вся графика и аудио загружаются асинхронно через Unity Addressables.

ТРЕБОВАНИЯ
----------
- Unity 2022.3 или новее
- Пакет: `com.unity.addressables` (Window → Package Manager)

БЫСТРЫЙ СТАРТ
-------------
1. Откройте демо-сцену:
   `Assets/VNKit/Demo/VNKitDemo.unity`
   и нажмите Play.

   (Если у вас пока нет графики, включите параметр **Use Placeholder Graphics** в настройках движка.)

2. В собственной сцене создайте движок:
```

GameObject → VNKit → Visual Novel Engine

```
Назначьте файл `.vns` (TextAsset) в поле **Start Script**.

3. Создайте папки для контента:
```

Tools → VNKit → Create Content Folders

```
Будут созданы следующие каталоги:
```

Assets/VNContent/Backgrounds/
Assets/VNContent/Characters/
Assets/VNContent/Audio/BGM/
Assets/VNContent/Audio/SFX/
Assets/VNContent/Audio/Voice/
Assets/VNScripts/

```

4. Сделайте ресурсы Addressable
(Window → Asset Management → Addressables → Groups)
и задайте для них **Address** согласно следующему соглашению.

КЛЮЧИ ADDRESSABLES
------------------
```

VN/Backgrounds/<Name>                  например: VN/Backgrounds/Campus
VN/Characters/<CharName>/<Appearance>  например: VN/Characters/Ayame/Smile
VN/Audio/BGM/<Name>
VN/Audio/SFX/<Name>
VN/Audio/Voice/<Name>

````

Префикс (`VN`) можно изменить в компоненте движка через параметр `resourcesRoot`.

ЗАГРУЗКА ПРИ ЗАПУСКЕ
--------------------
При запуске игры движок отображает экран загрузки, пока инициализируется Addressables.

При необходимости можно перечислить адреса ресурсов в поле **Preload Addresses** компонента движка — они будут предварительно загружены во время стартового экрана.

При выполнении команды LoadGame используется тот же экран загрузки.

СИНТАКСИС СЦЕНАРИЕВ
-------------------
```text
; комментарий
# Label
@bg Campus time:0.8              сменить фон с плавным переходом
@char Hana.Happy pos:left        показать/переместить персонажа
@char Hana hide                  скрыть персонажа
@hideChars time:0.5              скрыть всех персонажей
@bgm Theme fade:1.5              включить музыку
@stopBgm fade:1                  остановить музыку
@sfx Chime vol:0.8               воспроизвести звуковой эффект
@voice hana_01                   воспроизвести голосовую реплику
Hana: Dialogue line.             имя говорящего + текст
Hana.Happy: Changes + speaks.    сменить внешний вид и произнести реплику
Обычная строка повествования.
@choice "A" goto:La do:x+=1 | "B" goto:Lb if:x>0
@goto Label / @goto Script.Label
@set gold=100, affection+=2
@if affection>0 goto:Good else:Bad
@wait 1.5
@end
````

## УПРАВЛЕНИЕ

```
Space / Enter / ЛКМ        перейти к следующей реплике
Ctrl (удерживать)          пропуск текста (всегда, игнорируя режим "только непрочитанное")
Правая кнопка мыши         скрыть / показать интерфейс
Esc                        открыть настройки (или закрыть панели)
```

Быстрое меню также содержит:

* Auto (автопрокрутка)
* Skip (пропуск)
* Save (сохранение)
* Load (загрузка)
* Backlog (история диалогов)
* Settings (настройки)
* Title (главное меню)

## НАСТРОЙКИ

Интерфейс разделён на вкладки:

* **Sound** — громкость: общая, BGM, SFX и голосов.
* **Video** — выбор разрешения и полноэкранного режима (через `Screen.SetResolution`).
* **Game** — скорость текста, задержка автопрокрутки, режим «Пропускать только уже прочитанный текст», язык, список горячих клавиш (только для чтения).

Все настройки сохраняются в PlayerPrefs.

## ВОЗМОЖНОСТИ

* Интерфейс полностью создаётся во время выполнения с помощью `UIFactory` (CanvasScaler: ScaleWithScreenSize, базовое разрешение 1920×1080).
* Полностью Addressables-ориентированный конвейер загрузки ресурсов с кэшированием в памяти.
* Цветные временные спрайты-заглушки для быстрого прототипирования (`Use Placeholder Graphics`).
* Система сохранений и загрузок.
* История диалогов, выборы, переменные и выражения, переходы между различными сценариями через `@goto`.
* Режим пропуска учитывает настройку «только прочитанный текст», если она включена.
* Поддержка собственных команд `@commands` через событие `VisualNovelEngine.CustomCommand`.

## ПОЛЕЗНЫЕ СОВЕТЫ

* Демонстрационные сценарии находятся в:
  `Assets/VNKit/Demo/Scripts/`
* Для WebGL / itch.io рекомендуется минимизировать первоначальную загрузку, размещая крупные группы ресурсов как Remote.
* Включите **Use Placeholder Graphics**, чтобы писать и тестировать сценарии без готовой графики.
